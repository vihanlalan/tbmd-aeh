# Data Sources

All data in this project comes from verified, citable academic-grade sources.

## 1. Price Data

- **Source**: Yahoo Finance via `yfinance` library
- **Citation**: "Yahoo Finance. Historical market data. finance.yahoo.com"
- **Coverage**: Daily adjusted closing prices, 2005-01-01 to 2024-12-31
- **Universe**: S&P 100 current constituents (98 tickers after quality filtering)
- **Adjustments**: Prices are adjusted for splits and dividends

## 2. Market Factor

- **Source**: SPY ETF (SPDR S&P 500 ETF Trust) via `yfinance`
- **Rationale**: Avoids survivorship bias present in constructing an equal-weighted average from current constituents

## 3. Sentiment Data

- **Source**: FRED (Federal Reserve Bank of St. Louis)
- **Series**: UMCSENT — University of Michigan Consumer Sentiment Index
- **URL**: https://fred.stlouisfed.org/series/UMCSENT
- **Frequency**: Monthly — interpolated to daily, lagged 1 month (no lookahead)
- **Fallback**: AR(1) proxy if FRED API is unavailable

## 4. VIX (Visualisation Only)

- **Source**: CBOE via Yahoo Finance (`^VIX`)
- **Use**: Background shading in charts ONLY. **Not used in any performance calculation.**

## Survivorship Bias Warning

This project downloads **current** S&P 100 constituents. Companies removed from the index due to poor performance are NOT included. This biases all performance metrics upward by approximately 1-3% annualised.

For a survivorship-bias-free dataset, use CRSP/Compustat via WRDS.

## Cache Files

Cache files (`price_cache.csv`, `spy_cache.csv`, `sentiment_cache.csv`) are generated on first run and **not committed to version control**. They can be regenerated by running `scripts/run_realdata.py`.
